# Pre-Class - Transient Seepage

So far every seepage problem has been steady: the heads stay the same with time. When the boundary conditions change, the heads take time to catch up, and how long depends on how much water the soil stores and how fast it can pass it on. This lecture adds storage to the governing equation, shows how XSLOPE handles changing boundary conditions such as a falling reservoir, and works through a drawdown of an earth dam.
