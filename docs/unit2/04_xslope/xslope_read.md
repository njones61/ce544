# Pre-Class - Limit Equilibrium Analysis in XSLOPE

This lecture shows how to build, run, and review a limit equilibrium model in XSLOPE. It goes through each input in the order a model is built, with what it means, where it goes on the input template, and where it goes in XSLOPE Studio: global parameters and tension cracks, unit weights, strength, and pore pressure, profile lines and polygons, piezometric lines and water loads, distributed loads, and circular and non-circular surfaces. It then runs a search on the slope from the spreadsheet exercises and reads the results: the search and solution views, model checks, warnings, design, and reports.
